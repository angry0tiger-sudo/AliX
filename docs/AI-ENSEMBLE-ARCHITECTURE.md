# AliX Nobitex AI Ensemble Research Architecture

## Scope and promotion boundary

This branch is isolated from \`main\` and \`release/nobitex-mvp\`. The AI model is
research-only. Training, scoring, Kelly sizing, book-depth validation, and child
maker-slice planning do not grant order permission. The adapter has no order-write
method. \`Champion=null\`, \`order_permission=false\`, \`private_api_calls=0\`,
and \`trading_authorization=NO-GO\` remain hard invariants.

## Layer 1: causal features and labels

The required training frame is a 1-hour OHLCV series plus a separate, timestamped
microstructure archive. Features include RSI(14), MACD(12/26/9), ATR(14),
Bollinger %B/width, realized volatility, volume z-score, order-book imbalance,
taker buy/sell log ratio, and funding-rate context.

Microstructure rows must exactly match every OHLCV timestamp. Book observations
must lie inside their associated completed candle, and funding observations may
not come from the future. Missing rows, duplicate timestamps, invalid values,
and gaps fail closed. No interpolation, forward-fill, synthetic archive, or
future data is permitted.

Nobitex public OHLCV can be fetched in five backward-adjacent 365-day 1h windows
by \`scripts.fetch_nobitex_5y_ohlcv\`. The fetch fails unless all 43,800 candles
exist and are contiguous. A 1,825-day window is five 365-day years, not a
calendar-aware leap-year interval.

The target reuses AliX's ATR Triple-Barrier implementation: next-bar-open entry,
2 ATR take profit, 1 ATR stop loss, stop-loss precedence on same-bar collision,
and a 24-candle horizon. Realized outcome return is reduced by 50 bps round trip
(25 bps per maker side). The positive target means realized return after these
fees is greater than zero. This fee-only label geometry does not prove actual
maker fills, spread cost, or market impact.

## Layer 2: regime context

A custom three-state diagonal Gaussian HMM models log return, realized
volatility, and range fraction. State order is deterministic by mean return:
DOWN, RANGE, UP. The model uses the backward pass only for fitting HMM
parameters. The probability features exposed to the stack are strictly
forward-filtered \`P(state_t | observations_0..t)\` probabilities.

## Layer 3: ensemble probability

Level 0 contains LightGBM and XGBoost. Their predictions are generated by
expanding, purged inner walk-forward splits. Level 1 is a regularized Logistic
Regression model trained exclusively on those out-of-fold predictions plus
the three causal HMM probabilities. Logistic regression is used instead of
Ridge because the downstream contract requires a probability in [0, 1].

LSTM/GRU is intentionally not included. It remains excluded until an explicit
Owner approval authorizes a causal temporal model.

## Layer 4: risk gates

Fractional Kelly defaults to 1/4 Kelly. Expected reward and loss are reduced
and increased, respectively, by 50 bps round-trip fees. ATR volatility scaling,
a 0.5% maximum equity risk, and a 10% maximum equity notional cap are applied.
A non-positive after-cost reward or non-positive Kelly edge returns no position.

## Layer 5: Nobitex paper execution planning

The adapter calls the existing Nobitex MVP liquidity gate and passive maker
slice planner. It enforces a 0.5% mid-price band and at most 10% participation
per visible book level. A current, fresh public order-book snapshot must be
provided by the caller. The adapter returns a paper plan only.

The official published Spot order contract documents limit execution but does
not document an exchange-enforced post-only guarantee. A passive limit price
can become marketable between book observation and exchange acceptance.
Therefore this research integration contains no private API client, no order
submission method, and no fallback to taker or market orders.

## Training and validation

1. Fetch 1,825 days of contiguous public 1h OHLCV.
2. Supply a provenance-checked microstructure archive with the required columns.
3. Run \`python -m scripts.train_nobitex_ai_ensemble --ohlcv ... --microstructure ...\`.
4. Review nested purged expanding walk-forward metrics and Deflated Sharpe Ratio
   on non-overlapping trades.
5. Treat every model artifact as unpromoted until separate owner review and
   economic acceptance.

No profitability claim follows from code correctness or synthetic CI tests.
No paper trading session has been authorized by this architecture commit.
